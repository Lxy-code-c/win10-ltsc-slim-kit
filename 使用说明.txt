================================================================
 Win10 LTSC 中文版 一键精简 ISO 制作 —— 使用说明
================================================================

【这个工具包做什么】
  在安装镜像（install.wim）里【离线】移除下面这些组件，再打包回
  一个可直接安装的 ISO。装出来的系统是干净原生的，不会还原这些
  组件：
    · OneDrive 云同步
    · Microsoft Edge 相关保留项（LTSC 通常本身不带，脚本会检查）
    · Internet Explorer（旧版浏览器）
    · Windows Media Player 媒体播放器
    · Xbox / 游戏栏（Game Bar）
  并自动写入系统策略，关闭：
    · 遥测与数据收集（AllowTelemetry=0）
    · 建议应用、磁贴推广、广告 ID、消费者功能
    · Cortana 联网搜索 / WebSearch
    · OneDrive 自动启动

【自动优化设置 + 拦截弹窗广告】
  装出来的系统默认已预置（离线写入，装机即生效、所有账户生效）：
    · 拦截系统弹窗/广告：
        锁屏广告（Windows 聚焦/Spotlight 全关）
        任务栏「资讯和兴趣」弹窗
        通知中心、设置内的推广/建议内容
        搜索框建议、云推送通知推广
    · 拦截浏览器弹窗/广告（Edge、Chrome 装了即生效）：
        阻止弹窗（DefaultPopupsSetting=2）
        拦截侵入式广告（AdsSettingForIntrusiveAdsSites=1）
        注意：这是「由组织管理」的托管策略，浏览器设置里会显示被锁定，
        但可随时用以下命令删除还原（以管理员运行）：
          reg delete "HKLM\SOFTWARE\Policies\Microsoft\Edge" /f
          reg delete "HKLM\SOFTWARE\Policies\Google\Chrome" /f
    · 优化设置：
        关闭窗口透明效果（轻微提升图形性能，可在「个性化」改回）
        关闭首次登录动画、关闭提示建议类通知
    · 可选：网络层广告/弹窗域名拦截
        装好系统后，右键「可选-广告域名拦截.cmd」→ 以管理员运行
        会向 hosts 写入常见广告/追踪域名屏蔽，先自动备份 hosts，
        删除「LTSC-AdBlock」那段即可还原。
    · 装机后进阶优化（更激进，建议装机完成后运行一次）：
        右键「装机后-一键优化.bat」→ 以管理员运行。包含：
          电源计划→高性能、关闭休眠、禁用 SysMain/遥测服务、
          关闭全部视觉动画、清理临时文件；每项均附反向恢复方法。

【你需要准备】
  1. 一台 Windows 10/11 电脑（本套脚本在 Windows 上运行）
  2. Win10 LTSC 中文版 ISO 文件 —— 见下方「怎么获取原版 ISO」
  3. （可选，但强烈建议）Windows ADK
     · 官方免费下载：https://learn.microsoft.com/windows-hardware/get-started/adk-install
     · 安装时勾选「Deployment Tools」即可
     · 这是用于最后打包 ISO 的官方工具（oscdimg）
  4. 磁盘剩余空间至少 15GB

【怎么获取原版 ISO（脚本已自动引导）】
  一键制作.bat 运行时若发现本文件夹没有 LTSC.iso，会自动打开
  00-下载ISO.ps1 引导获取，三种方式任选：
    [1] 自动打开微软官方评估中心（推荐，正版）
        微软官方免费原版通道。浏览器会弹出页面，你按提示点一下：
        选 Enterprise → 语言「中文（简体）」→ 位宽「64位」→ 下载。
        注意：评估中心下载页设有人机验证，必须由你在浏览器里点一次，
        脚本无法完全自动完成这最后一步（微软官方与各镜像站均如此）。
        下载完成后把 ISO 放到本文件夹并改名为 LTSC.iso。
    [2] 你已有原版 ISO → 放进本文件夹改名为 LTSC.iso
    [3] 你有直链 → 脚本自动用 BITS 下载
  下载/放入后脚本会自动校验（大小 + ISO9660 标识）。

  提示：LTSC 2021 的中文原版 ISO 官方只通过「评估中心 / MSDN / VLSC」
        提供。网上所谓"精简版/优化版/纯净版"均为第三方二次修改，来源
        与安全无法保证，强烈建议只用本脚本从原版自己精简。

【怎么用】
  1. 把本工具包放到 Windows 电脑上任意文件夹
  2. 右键「一键制作.bat」→ 以管理员身份运行
  3. 脚本会：缺 ISO 时自动引导下载 → 解压 → 精简 → 打包，全程自动
  4. 完成后本文件夹出现  Win10LTSC_精简版_日期.iso ，用它装机即可

【只想分步跑（便于排查）】
  01-解压镜像.ps1   —— 挂载 ISO、复制镜像内容到「工作目录」
  02-一键精简.ps1   —— 核心：移除组件 + 写注册表策略（管理员）
  03-打包ISO.ps1    —— 注入应答文件并用 oscdimg 打包 ISO

【不装 ADK 的替代打包方式（推荐给新手）】
  如果不想装 Windows ADK，可以：
  1. 只跑前两步（01、02），得到修改好的「工作目录\镜像内容」
  2. 用 NTLite 免费版（www.ntlite.com）：
      文件 → 加载镜像(工作目录\镜像内容\sources\install.wim)
      → 左侧「应用更改」→ 保存 → 「另存为 ISO」
     NTLite 免费版即可直接导出 ISO，界面全图形化。

【注意事项】
  · 每一步都要「以管理员身份运行」，否则挂载/写入会失败。
  · 若镜像里没有某个组件（如 LTSC 本身不带 OneDrive），脚本会
    自动跳过，不会报错中断。
  · 移除 IE / 媒体播放器后，部分老网站/老课件可能无法打开多媒体，
    请自行评估是否保留（脚本已做成可跳过）。
  · autounattend.xml 会：自动设中文区域、跳过隐私设置、隐藏在线账户页；
    但它【不内置产品密钥】，也【仍需你创建本地账户】——不是全程零交互，
    这点是之前说明写过头了，已更正。LTSC 评估版安装无需密钥，装完按需激活。
  · 建议先做一次安装测试（虚拟机或闲置机器）再正式使用。

【目录结构】
  LTSC-精简镜像工具包\
    一键制作.bat         总入口（管理员运行，缺ISO会自动引导下载）
    00-下载ISO.ps1       获取原版 LTSC ISO（评估中心/已有ISO/直链）
    01-解压镜像.ps1
    02-一键精简.ps1
    03-打包ISO.ps1
    autounattend.xml      无人值守应答文件
    装机后-一键优化.bat   装机完成后进阶优化
    可选-广告域名拦截.cmd 网络层 hosts 广告拦截
    LTSC.iso              原版镜像（脚本自动下载/引导放入）
    工作目录\             运行时自动生成（镜像内容、挂载点）
    Win10LTSC_精简版_*.iso  成品输出
