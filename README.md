# Win10 LTSC 一键精简工具包

从**微软原版 Windows 10 Enterprise LTSC 2021 中文版 ISO** 出发，离线移除多余组件、预置系统/浏览器广告拦截与优化策略，并重新打包成可直接安装的干净 ISO。全部为 PowerShell + 批处理脚本，**不修改系统镜像以外的任何东西，不上传数据**。

## 功能

- **离线精简**（改的是 `install.wim`，装完不会还原）：OneDrive、Internet Explorer、Windows Media Player、Xbox / 游戏栏。
- **广告 / 弹窗拦截**（策略写进镜像，所有账户生效）：
  - 锁屏广告、Windows 聚焦(Spotlight)、资讯和兴趣、通知推广、设置内建议
  - Edge / Chrome 阻止弹窗 + 拦截侵入式广告
- **隐私与优化**：关闭遥测、广告 ID、Cortana 联网搜索、OneDrive 自启、窗口透明效果；新用户默认模板同步生效。
- **无人值守辅助**：注入 `autounattend.xml`，自动设中文区域、跳过隐私设置。
- **装机后可选**：`装机后-一键优化.bat`（电源/休眠/后台服务/动画）、`可选-广告域名拦截.cmd`（hosts 网络层拦截）。

## 文件结构

| 文件 | 作用 |
|---|---|
| `一键制作.bat` | 总入口，自动提权；缺 ISO 时自动进入下载引导 |
| `00-下载ISO.ps1` | 获取原版 ISO（评估中心 / 已有 ISO / 直链三选一） |
| `01-解压镜像.ps1` | 挂载 ISO、复制镜像内容到「工作目录」 |
| `02-一键精简.ps1` | 核心：移除组件 + 写注册表策略（含删除回查、hive 载入校验） |
| `03-打包ISO.ps1` | 注入应答文件 + oscdimg 打包 ISO（退出码/大小校验） |
| `autounattend.xml` | 无人值守应答文件 |
| `装机后-一键优化.bat` | 装机完成后进阶优化（可反向恢复） |
| `可选-广告域名拦截.cmd` | hosts 广告/追踪域名拦截（带备份） |
| `使用说明.txt` | 详细中文说明 |

## 使用方法

1. 装好 **Windows ADK**（勾选 *Deployment Tools*，提供 `oscdimg`）。不想装 ADK 也可只跑前两步，用 NTLite 免费版把 `工作目录\镜像内容\sources\install.wim` 另存为 ISO。
2. 准备原版 LTSC 中文版 ISO（见下节）。
3. **右键 `一键制作.bat` → 以管理员身份运行**。
4. 依次：缺 ISO 自动引导 → 解压 → 精简 → 打包，产物为本目录下 `Win10LTSC_精简版_日期.iso`。
5. 装机完成后，可选运行 `装机后-一键优化.bat`、`可选-广告域名拦截.cmd`。

## 获取原版 ISO（重要）

LTSC 2021 中文原版 ISO 官方仅通过 **微软评估中心 / MSDN / VLSC** 提供，没有可被脚本静默自动下载的公开直链（评估中心与各镜像站均有人机验证）。因此 `00-下载ISO.ps1` 采用“自动优先 + 官方一键兜底”：自动打开微软官方评估中心页面，按提示点一次下载，再放入本目录并命名为 `LTSC.iso`。

> 脚本会对 ISO 做完整性校验（大小 + ISO9660 标识）。请勿使用来源不明的“精简版/纯净版”第三方 ISO。

## 已知限制 / 注意事项

- 需在 **Windows** 上运行（依赖 DISM、`reg`、`Mount-DiskImage`、`oscdimg`）。
- 工作目录路径**不能含空格**（oscdimg 的 `-bootdata` 参数限制），脚本会检测并提示。
- `autounattend.xml` **不内置产品密钥**，仍需创建本地账户；LTSC 评估版安装无需密钥，激活请使用你自己的合法授权。
- IE / 媒体播放器可能被系统保护而无法移除，脚本会明确告警而非假装成功。
- 建议先在虚拟机或闲置机器验证后再正式使用。
